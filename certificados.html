Regras de Emissão

  • Conclusão mínima de 90%: O certificado só é emitido quando o aluno conclui pelo menos 90% das aulas do curso.
  • Projeto final aprovado: O aluno deve entregar e ter o projeto final aprovado pela banca docente.
  • Código único: Cada certificado recebe um código único no formato CA-ANO-XXXX para validação pública.
  • Validade permanente: Certificados não expiram e podem ser verificados a qualquer momento nesta página.
  • Horas complementares: Certificados são aceitos como horas complementares conforme Decreto nº 5.154/2004.

Validação pública: Qualquer pessoa pode verificar a autenticidade de um certificado usando o código impresso. Esta página consulta o banco de dados oficial da Cyber Academy.
